# Инструкция пользователя medogen

medogen собирает тестовые пакеты МЭДО форматов 2.7.1 и 3.0. С его помощью проверяют, как СЭД
принимает входящие пакеты и отвечает на них. В каждом пакете есть envelope.ini, message.xml и
транспортный контейнер (*.edc.zip). После сборки пакет сразу проверяется по XSD и на
обязательные реквизиты.

Работать можно в браузере (интерфейс для тестировщиков) или из командной строки (сценарии JSON).
Справочник по всем полям сценариев и форматам приведён в [README](../README.md).

## 1. Запуск

**На своём компьютере.** Нужен Python 3.8 или новее. Откройте папку medogen и запустите
`run_ui.bat` или выполните команду:

```
python medogen.py ui
```

Браузер откроется на http://localhost:8765. Чтобы остановить сервер, нажмите Ctrl+C в окне
консоли.

**На общем сервере.** Откройте адрес, который дал администратор, например
`http://medogen.corp.local`. Устанавливать ничего не нужно. Как развернуть сервер, описано в
[DEPLOY.md](DEPLOY.md).

Для проверки по XSD нужен пакет lxml (`pip install lxml`). Без него пакеты собираются, но
схемы не проверяются, о чём интерфейс предупреждает в шапке.

## 2. Стенд и справочники

В шапке выбирается **стенд**: набор организаций с GUID и адресами МЭДО. GUID на разных стендах
различаются, поэтому для каждого тестового контура заводится свой стенд (вкладка «Организации»
→ «Новый стенд»).

**Справочник ГАС ГосЭДО** содержит всех абонентов МЭДО (около 36 тысяч). Так берутся
реальные адреса и GUID, которые сверяет проверочный бот МЭДО. Чтобы загрузить справочник:

1. Откройте в браузере https://gosedo.ru/wp-content/uploads/files/addresseesActual.html и сохраните
   страницу (Ctrl+S, «Веб-страница полностью» или «только HTML»).
2. Вкладка «Организации» → «Справочник ГАС ГосЭДО» → «Загрузить» → выберите сохранённый файл.

Справочник обновляют раз в месяц или когда бот сообщает, что адреса нет в ГАС
(показатели 1.3 и 1.8).

## 3. Собрать пакет

Вкладка **«Создать пакет»**:

1. Выберите формат (3.0 или 2.7.1) и тип пакета: исходящий документ, ТК ГосЭДО, обращение
   гражданина, квитанция, уведомление, цифровое поручение.
2. Выберите отправителя и получателей. Их можно взять из стенда или найти в ГАС через поле
   поиска под списком: по названию, адресу МЭДО или GUID.
3. Заполните поля документа. Обязательные поля отмечены звёздочкой (*). Поля с подсказкой
   «авто» можно оставить пустыми: номер, дату и ФИО по умолчанию подставит генератор.
   Регистрационный номер по умолчанию каждый раз новый, например MG-2110-171018-1.
4. Нажмите «Собрать пакет». Если обязательное поле не заполнено, пакет не соберётся: поле
   подсветится красным, а над кнопкой появится список. Щелчок по строке списка ведёт к полю.

Справа появится результат: GUID сообщения и документа (копируются по щелчку), состав пакета
с просмотром любого файла и результат проверки. Ниже кнопки:

- **Скачать .zip** — пакет одним архивом, его загружают в СЭД или в проверочный бот МЭДО;
- **Ответный документ, Квитанция, Уведомление, Событие по поручению** — ответ на этот пакет:
  форма заполняется сама, отправитель и получатель меняются местами.

«Очистить форму» сбрасывает и форму, и блок результата.

**Цифровое поручение.** У каждого пункта есть номер, срок, текст, исполнитель и
соисполнители. Исполнителя и соисполнителей можно найти в ГАС через поля под списками. Если
поле «Получатели» пустое, получатели берутся из исполнителей и соисполнителей пунктов.

## 4. Входящий пакет из СЭД и ответы пачкой

Вкладка **«Пакеты»** → загрузите пакет из СЭД: .zip, файлы (envelope.ini, message.xml,
*.edc.zip) или папку. Можно просто перетащить их в окно.

1. Пакет проверяется: XSD, обязательные реквизиты, формат UUID и дат. Если загружен полный
   справочник ГАС, адреса и GUID сверяются с ним так же, как это делает бот. Расхождения с ГАС
   показаны отдельным блоком «Сверка с ГАС».
2. Откроется окно **«Ответы пачкой»**. Отметьте нужные ответы: квитанции о приёме или отказе,
   уведомления, ответный документ. Затем нажмите «Сформировать ответы». Каждый ответ
   собирается отдельным пакетом, все их можно скачать одним архивом.

## 5. Проверочный бот МЭДО

Собранный пакет (.zip) можно проверить в «Валидаторе сообщений МЭДО». Если бот нашёл
ошибку, сохраните отчёт (validation-report.html) и передайте его вместе с пакетом
разработчику. Каждую ошибку бота закрепляют тестом в `tests/test_bot_findings.py`.

## 6. Командная строка

```
python medogen.py build examples                  собрать все примеры
python medogen.py build мой_сценарий.json --zip   собрать свой сценарий и упаковать в .zip
python medogen.py validate <папка пакета>         проверить любой пакет, в том числе из СЭД
python medogen.py gas Тюменская область           поиск в справочнике ГАС
python -m unittest discover -s tests -v           автотесты (или run_tests.bat)
```

Любой пакет, собранный в интерфейсе, можно выгрузить кнопкой «Показать JSON сценария». Этот
сценарий соберёт такой же пакет из командной строки.

## 7. Где лежат файлы

| Что | Где |
|---|---|
| Пакеты из интерфейса | `out/ui/<дата-время>_<тип>` |
| Входящие пакеты, загруженные в интерфейс | `out/ui/_incoming` |
| GUID и номера собранных пакетов | `out/ui/_manifests/*.json` |
| Стенды (организации) | `orgs/*.json` |
| Справочник ГАС | `gas/gas.json` |

## 8. Ограничения

- Подписи (.p7s и XMLDSig в digital.xml) делаются встроенным тестовым сертификатом «MEDOGEN
  TEST SIGNER». По формату они корректны, но СЭД, которая проверяет доверие к сертификату,
  их отклонит. Подписывать .p7s настоящим ключом КриптоПро можно в сценариях командной строки
  через `settings.sign_command` (см. README, раздел «Подписи»).
- Генерируются только форматы 2.7.1 и 3.0.
- Принятые допущения перечислены в README, раздел «Допущения».
